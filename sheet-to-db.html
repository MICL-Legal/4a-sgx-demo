請把課堂 Repo 下載到另一個暫存位置，讀完 README.md、CLAUDE.md、prompts/sheet-to-db.md。不要執行課堂範例、不要覆蓋我的作品，也不要修改暫存 Repo。

請找出我的作品讀寫 Google 試算表的位置，並用繁體中文告訴我：
1. 我的作品與暫存 Repo 分別在哪裡
2. 課堂 Repo 要我完成哪些步驟
3. 目前資料如何讀寫 Google 試算表
4. 搬到資料庫前，需要確認哪些欄位與工作規則

先不要修改，等我確認後再開始。

第二階段 · 我確認後才搬 —— 我確認後，把下面整段複製，貼給 Claude Code：
第二階段提示詞
開始前先確認 DB helper 已安裝且設定完整；只回報「完整／不完整」，不要顯示任何值。不要詢問部門、工號、主機、帳號、密碼或連線字串。

資料庫只能使用 helper 提供的 SQL Login、MEDTECS_DB_DATABASE 與 MEDTECS_DB_SCHEMA；若設定或權限不符，請停止並請講師協助。

我確認後，請依序執行：
1. 保留原始 Google 試算表，不直接刪除或修改
2. 用白話列出欄位、必填、重複與其他工作規則
3. 透過 DB helper 連線，不顯示帳密
4. 先搬少量資料，回報成功、重複與失敗筆數
5. 我確認後才搬完整資料並修改作品
6. 重開作品，測試新增、修改、查詢與原有功能
7. 整理修改內容、資料核對與測試結果

大量修改、刪除資料或公開內容前，一定先問我。
