一組四頁的教學示範。全部是純靜態 HTML，**沒有後端、沒有 API 呼叫、沒有 API key**，雙擊就能開，也可以放上 GitHub Pages 分享連結。

| 檔案 | 內容 | 什麼時候用 |
|---|---|---|
| `index.html` | **講師版**：一條輸入，兩套系統同時跑，含判錯計分板 | 上課投影主用 |

四頁最上面有共用導覽列，可以互相跳。

## 上 GitHub Pages（網頁介面，不用裝 git，約 3 分鐘）

1. 到 <https://github.com/new> 建一個 repo，例如 `4a-sgx-demo`
   - Public（Pages 免費方案只支援公開 repo，見下方「先確認一件事」）
   - 不要勾 Add a README
2. 進 repo → 點 **uploading an existing file**
3. 把這四個 `.html` 檔一次拖進去 → **Commit changes**
4. **Settings** → 左欄 **Pages**
   - Source：`Deploy from a branch`
   - Branch：`main` ／ 資料夾 `/ (root)` → **Save**
5. 等 1–2 分鐘，網址會長這樣：

```
https://<你的帳號>.github.io/4a-sgx-demo/
```

打開就直接是講師版（因為講師版就是 `index.html`）。

之後要改內容：在 GitHub 上點檔案 → 鉛筆圖示 → 改 → commit，一分鐘後自動更新。

## 先確認一件事（跟你的職務有關）

GitHub Pages 免費方案的 repo 是**公開**的，也就是這個網址任何人都能開，Google 也會收錄。

而這四頁裡目前有：

- 真實同事名字：陳美玲、劉靜怡、王志明、李文凱、張建國、黃淑芬
- 真實子公司：子公司甲、子公司乙（海外製造）、RMSG、子公司丁（保稅園區）
- 虛構但寫得很像真的情境：「某海外子公司廠火災停工三週」、「子公司乙 本月未回報」、「公司被 SGX 盯上、董事被點名」

案例是編的，但**名字和實體是真的**。以 SGX 上市公司法務的立場，這種東西掛在公開網址上、脫離上課情境被看到，不見得是你想要的。

三個選項：

- **A. 換成中性代號**（Entity 1–4、通報人 A–D、情境改成「某製造子公司」）→ 掛公開網址沒有負擔。要的話跟我說，我一次改完給你。
- **B. 不公開**：用 Cloudflare Pages ＋ Cloudflare Access，限定公司 email 才能開（你之前研究過 Cloudflare Pages，這條路你熟）。
- **C. 完全不上線**：這四個檔**離線就能跑**，雙擊就開，會場沒網路也照樣示範。純粹要分享的話，丟公司雲端硬碟就好。

實務上如果只是為了上課投影，**C 最安全也最省事**；要學員自己在手機上玩才需要 A 或 B。

## 會場注意

- **字型**：頁面用 Google Fonts，沒網路時會退回系統字型（微軟正黑／蘋方），版面不會壞，只是比較不好看。
- **離線備案**：把四個檔存進電腦（同一個資料夾），雙擊 `index.html` 就能跑，導覽列也照樣能互跳。建議會場前先存一份。
- **講師版快捷鍵**：`1`–`5` 帶入案例、`Enter` 執行、`R` 攤開 A 的 16 個關鍵字、`N` 下一筆、`0` 重設計分。右上角有全螢幕。
