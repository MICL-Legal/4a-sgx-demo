把 Google Sheets 接進 Claude Code

做完這頁,你打一句話 Claude Code 就能讀寫你的 Google 試算表(這就是 Devin 飲料店那個「說→做」的底層)。跟著做、每一步都有直接連結,不用自己找。

開始前(必讀兩點):
1. 用你的公司 Google 帳號登入 console.cloud.google.com(看到「同意條款」先同意)。
2. 認明專案名稱。每個連結打開後,看畫面最上方那條藍色列——它會顯示你現在選到的專案。下面 5 步一定要在「同一個專案」裡做完,不然最後工具讀不到東西(這是最常見的失敗)。列上不是你的專案?點它 → 選你的專案。
1

建立專案必做

打開「建立專案」頁console.cloud.google.com/projectcreate開 ↗
做: 在 Project name 欄輸入好記的名字(例 gsheets-workshop)→ 按左下角藍色 CREATE。
成功長這樣: 約 10–30 秒後,最上方藍色列變成你的專案名。點藍色列 → 記下那串 Project ID(像 gsheets-workshop-471203,全小寫含數字)——這串等下指令要用,不是中文顯示名。
別碰: Location/Organization 保持預設(個人帳號多半顯示 No organization)。ID 不用按 Edit(建好不能改)。
2

開啟 Google Sheets API必做

打開「Google Sheets API」頁console.cloud.google.com/apis/library/sheets.googleapis.com開 ↗
做: 按藍色 ENABLE(啟用)。
成功長這樣: 頁面重整,原本的 ENABLE 消失、變成 MANAGE(管理)。看到 MANAGE = 開好了。
別碰: 按之前先確認藍色列是步驟 1 那個專案(在錯的專案開 API 是常見錯)。頁面上的「建立憑證」按鈕這步先別按。
3

建立服務帳戶(Service Account)必做

打開「服務帳戶」頁console.cloud.google.com/iam-admin/serviceaccounts開 ↗
做: 頁面頂端按 + CREATE SERVICE ACCOUNT → 在名稱欄輸入(例 sheets-bot)→ 直接按 DONE。
成功長這樣: 回到列表,多一列,Email 欄是一長串、結尾 @你的專案.iam.gserviceaccount.com。看到這個 email 就成功(下一步、第 5 步都要用它)。
別碰(重要): 按完名稱若跳出第二個面板「授予角色(選用)」——不要選任何角色,直接 DONE 跳過。權限靠第 5 步「分享那張表」給它就好,給專案角色反而多餘、還可能被公司政策擋。
4

幫它產生 JSON 金鑰必做

做: 點步驟 3 那個服務帳戶的 email(藍字)進去 → 上方 KEYS 分頁 → ADD KEY → Create new key → 選 JSON → CREATE。
成功長這樣: 瀏覽器自動下載一個 .json 檔(通常在「下載」資料夾),並跳「Private key saved」。這個 .json 的完整路徑,就是等下指令裡的金鑰路徑。
別碰(重要): Key type 保持 JSON。這檔只會下載這一次、無法重載——把它從「下載」移到一個路徑不含空格的固定資料夾(Mac 例 ~/gsheets-key/、Win 例 C:/gsheets-key/)。這是密碼等級機密:不要 email、不上傳、不放 git。
拿到完整路徑: Mac — 把檔案拖進終端機會自動貼路徑;Windows — 對檔案按住 Shift + 右鍵 → 複製為路徑,再把 \ 換成 /。
5

把 Demo 試算表「分享」給服務帳戶必做

少了這一步,工具什麼都看不到——這是最常見的卡關。
做: 打開你的 Demo Google Sheet → 右上角 共用/Share → 貼上服務帳戶的 email(第 3/4 步那個 …@專案.iam.gserviceaccount.com)→ 角色選 Editor(編輯者) → 取消勾「通知使用者/Notify people」 → 按 共用/Share。
成功長這樣: 再按一次共用,「有存取權的人」清單裡看得到那個服務帳戶 email、標示 Editor。
別碰: 角色務必 Editor(選 Viewer 就不能寫入)。一定要取消「通知使用者」(服務帳戶沒信箱,寄了沒人收)。「一般存取權」保持 Restricted 即可,不用開成「任何知道連結的人」。
email 從哪來:服務帳戶列表的 Email 欄直接複製;或用記事本打開第 4 步的 JSON,裡面 client_email 那行就是。

最後一步:跑一行,接好

你不用碰任何設定檔——把上面 JSON 的路徑貼進下面那行的引號中間,跑一次就接好(它會自動讀出 project id)。

Mac
bash <(curl -fsSL https://raw.githubusercontent.com/MICL-Legal/4a-sgx-demo/main/install-sheets-mcp.sh) "把你的JSON完整路徑貼這裡"
Windows PowerShell
iwr https://raw.githubusercontent.com/MICL-Legal/4a-sgx-demo/main/install-sheets-mcp.ps1 -OutFile "$env:TEMP\s.ps1"; & "$env:TEMP\s.ps1" "把你的JSON完整路徑貼這裡"
✓ 成功長這樣: 重開 Claude Code、打 claude mcp list,看到 mcp-gsheets ✔ Connected 就通了(第一次可能等 ~30 秒下載)。之後在 Claude 裡說「把這筆寫進我的 XX 試算表」就會動。
