# order-demo-3 飲料訂購系統 — 交接安裝手冊（零基礎版）

> 適用對象：完全沒碰過程式的同事
> 文件版本：v1.0（2026-08-03）
> 系統簡介：一個網頁訂購系統，資料存在 Google 試算表（Google Sheets），在自己電腦上啟動後用瀏覽器操作。

---

## 第〇章：交接方（打包的人）要做的事

### 0-1 打包範圍

只壓縮 `order-demo-3` 資料夾，但**先刪掉（或排除）裡面的 `.venv` 資料夾**：

```
order-demo-3\
├── app.py             ✅ 要
├── index.html         ✅ 要
├── main.py            ✅ 要
├── pyproject.toml     ✅ 要
├── uv.lock            ✅ 要
├── .python-version    ✅ 要
├── 啟動伺服器.bat      ✅ 要
└── .venv\             ❌ 不要壓（體積大、綁定原電腦，對方會自動重建）
```

### 0-2 絕對不能給的東西

- ❌ `credentials\service_account.json`（你的 Google 金鑰）**絕對不能一起壓縮或用通訊軟體傳送**。
  這把金鑰等於你 GCP 專案的鑰匙，同事要用自己的（第二章教他自己申請，免費）。
- 好消息：金鑰放在 `order-demo-3` 的上一層資料夾，所以只壓 `order-demo-3` 不會誤帶。壓縮前仍請打開壓縮檔目視確認一次。

### 0-3 建議一併提供給同事

1. 這份手冊（轉成 Word）。
2. 你的 Google 試算表**檢視連結**（讓同事照著「建立副本」，欄位格式才不會弄錯）。
   或直接告訴他表格結構（見附錄 A）。

## 第一章：同事收到檔案後 — 環境安裝（約 15 分鐘）

### 1-1 解壓縮並建立資料夾結構

在電腦任意位置（例如 `D:\`）建立一個母資料夾 `order-system`，結構**必須**長這樣：

```
D:\order-system\
├── order-demo-3\          ← 解壓縮出來的專案資料夾
│   ├── app.py
│   ├── index.html
│   └── ...（其他檔案）
└── credentials\           ← 自己手動新建的空資料夾（名稱一字不差）
    └── service_account.json  ← 第二章申請下載後放這裡
```

⚠️ 重點：`credentials` 資料夾要建在 `order-demo-3` 的**旁邊**（同一層），不是裡面。
因為程式是到「上一層的 credentials 資料夾」找金鑰。

### 1-2 安裝 uv（Python 環境管理工具）

1. 按 `Windows鍵`，輸入 `powershell`，開啟「Windows PowerShell」。
2. 複製貼上以下指令後按 Enter：
   ```
   powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
   ```
3. 跑完後**關掉 PowerShell 再重開一個**，輸入 `uv --version`，有出現版本號（如 `uv 0.6.x`）就成功。

> 不需要另外安裝 Python — 第一次啟動時 uv 會自動下載 Python 3.13 和所有需要的套件（需要網路）。

## 第二章：申請自己的 Google 服務帳號（免費，約 10 分鐘）

> 「服務帳號」= 給程式用的 Google 機器人帳號。程式用它的金鑰去讀寫你的 Google 試算表。

### 2-1 建立 GCP 專案

1. 用自己的 Google 帳號登入 https://console.cloud.google.com
2. 第一次使用會要求同意條款 → 勾選同意。
3. 點畫面上方的**專案選單** →「新增專案」→ 專案名稱隨意取（如 `order-demo`）→「建立」。
4. 建好後確認畫面上方顯示的是剛建立的專案名稱。

（此流程不需要綁信用卡、完全免費。）

### 2-2 啟用 Google Sheets API

1. 左上角 ☰ 選單 →「API 和服務」→「程式庫」。
2. 搜尋 `Google Sheets API` → 點進去 → 按「啟用」。
3. （保險起見）同樣方式再啟用 `Google Drive API`。

### 2-3 建立服務帳號

1. ☰ 選單 →「IAM 與管理」→「服務帳戶」。
2. 按「＋建立服務帳戶」。
3. 服務帳戶名稱：隨意取（如 `order-bot`）→「建立並繼續」。
4. 「授予這個服務帳戶專案的存取權」→ 可直接按「繼續」跳過 →「完成」。
5. 建立完成後，**把畫面上顯示的服務帳戶電子郵件抄下來**，長得像：
   `order-bot@order-demo-xxxxxx.iam.gserviceaccount.com`
   （第三章分享試算表會用到。）

### 2-4 下載金鑰 JSON 檔

1. 在服務帳戶清單中點剛建立的帳戶 → 上方「金鑰」分頁。
2. 「新增金鑰」→「建立新的金鑰」→ 選 `JSON` →「建立」。
3. 瀏覽器會自動下載一個 `.json` 檔。
4. 把它**改名為 `service_account.json`**（一字不差），移動到第一章建好的：
   `D:\order-system\credentials\service_account.json`

⚠️ 這個檔案等同密碼，不要上傳雲端、不要用 LINE/Email 傳給別人。

## 第三章：建立自己的 Google 試算表

### 3-1 建立試算表與兩個工作表

1. 開 https://sheets.google.com →「＋ 空白試算表」。
2. 試算表名稱隨意取（如 `飲料訂購系統`）。
3. 左下角的工作表分頁需要**兩個**，順序不能錯：
   - 第 1 個分頁：庫存表（名稱隨意，但必須排在第一個）
   - 第 2 個分頁：訂單表（按左下角「＋」新增，必須排在第二個）

### 3-2 填入表頭與資料

**第 1 個分頁（庫存表）** — 第 1 列填表頭，第 2 列起填品項：

| A | B | C |
|---|---|---|
| 品項ID | 品項名稱 | 總庫存 |
| A001 | 四季春青茶 | 10 |
| A002 | 錫蘭紅茶 | 10 |
| A003 | 三兄弟 | 10 |
| A004 | 波霸奶茶 | 10 |
| A005 | 珍珠奶茶 | 10 |

> D 欄「剩餘庫存」**不用自己填**，程式第一次啟動會自動建立。
> 品項可自行增減，但 A/B/C 欄格式要照上表。

**第 2 個分頁（訂單表）** — 只填第 1 列表頭，內容留空：

| A | B | C | D |
|---|---|---|---|
| 時間 | 姓名 | 品項ID | 品項名稱 |

### 3-3 把試算表分享給服務帳號

1. 試算表右上角「共用」。
2. 貼上 2-3 步驟抄下的服務帳戶電子郵件（`xxx@xxx.iam.gserviceaccount.com`）。
3. 權限選「**編輯者**」→ 取消勾選「通知使用者」→「傳送／共用」。

> 沒做這步，程式會報權限錯誤（403）。

### 3-4 取得試算表 ID

看瀏覽器網址列：

```
https://docs.google.com/spreadsheets/d/【這一長串就是試算表ID】/edit#gid=0
```

把 `/d/` 和 `/edit` 之間那串英數字複製起來，下一章要用。

## 第四章：修改程式中的試算表 ID（唯一要改的地方）

1. 到 `D:\order-system\order-demo-3\`，在 `app.py` 上按右鍵 →「開啟檔案」→ 選「記事本」。
2. 找到第 15 行（檔案很前面）：
   ```python
   SHEET_ID = "1X-k7SPlzoB4NgAUuIabVYdKv74SOFgTwRj90Y6cISBI"
   ```
3. 把雙引號**裡面**那串換成 3-4 複製的自己試算表 ID。雙引號要保留，例如：
   ```python
   SHEET_ID = "把你的ID貼在這裡"
   ```
4. 存檔（Ctrl+S）後關閉記事本。

> 整個專案**只需要改這一行**，其他檔案都不用動。

## 第五章：啟動與使用

1. 進入 `D:\order-system\order-demo-3\`，**雙擊 `啟動伺服器.bat`**。
2. 第一次啟動會自動下載 Python 與套件（1～3 分鐘，需網路），之後啟動都是幾秒鐘。
3. 看到類似 `Running on http://127.0.0.1:5000` 的字樣後，開瀏覽器輸入：
   `http://127.0.0.1:5000`
4. 看到飲料訂購畫面即成功。下單後可到 Google 試算表確認訂單有寫入。
5. 關閉系統：關掉黑色視窗即可。

## 第六章：常見問題（FAQ）

| 症狀 | 原因 | 解法 |
|---|---|---|
| 黑窗閃一下就消失 | uv 未安裝成功 | 重做 1-2，關閉重開 PowerShell 確認 `uv --version` |
| `FileNotFoundError ... service_account.json` | 金鑰位置或檔名不對 | 確認結構同 1-1：`credentials` 在 `order-demo-3` 旁邊、檔名一字不差 |
| 錯誤訊息含 `403` / `PERMISSION_DENIED` | 試算表沒分享給服務帳號 | 重做 3-3，權限必須是「編輯者」 |
| 錯誤訊息含 `404` / `not found` | SHEET_ID 貼錯 | 重做 3-4、第四章，注意不要多複製到斜線 |
| 錯誤訊息含 `API has not been enabled` | Sheets API 沒啟用 | 重做 2-2，啟用後等 1～2 分鐘再試 |
| 網頁打不開 | 伺服器沒在跑 | 確認黑色視窗還開著且顯示 Running on... |
| 訂單頁面報錯 | 訂單表表頭不對 | 第 2 分頁第 1 列必須是：時間、姓名、品項ID、品項名稱 |

## 附錄 A：試算表結構總覽

- 工作表順序固定：第 1 個 = 庫存表、第 2 個 = 訂單表（程式用順序讀取，不看名稱）。
- 庫存表：A=品項ID、B=品項名稱、C=總庫存、D=剩餘庫存（程式自動維護）。
- 訂單表：A=時間、B=姓名、C=品項ID、D=品項名稱（表頭文字必須一字不差）。
- 品項的表情符號與說明文字寫在 `app.py` 的 `DRINK_META`（第 21 行附近），新品項若沒設定會用預設 🥤，不影響功能。

## 附錄 B：安全守則（務必遵守）

1. `service_account.json` = 密碼，每人申請自己的一把，不互傳、不上傳雲端硬碟/群組。
2. 若金鑰不小心外流：到 GCP「服務帳戶 → 金鑰」刪除舊金鑰、重新建立一把即可（舊的立刻失效）。
3. 此系統只在自己電腦執行（127.0.0.1），關掉黑窗即停止，外部無法連入。
